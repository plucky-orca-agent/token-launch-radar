How the ranking is made

A protocol joins the board when the snapshot records no token for it — no CoinGecko id, no symbol — and it is an independent protocol, not a wrapped, staked or bridged product and not an exchange balance sheet. Its implied value is built only from the snapshot's own figures:

implied value = TVL × category multiple × growth × maturity × launch factor

  • Category multiple — the median market-cap / TVL ratio of the token-bearing protocols in the same DefiLlama category, computed from this snapshot. A category with fewer than 3 priced peers uses the all-category median (—). No flat multiple is imposed and no name is special-cased.
  • Growth — 1 + clamp(7-day TVL change, −50%…+100%) × 0.35. A hot week lifts a value; it never makes one.
  • Maturity — 0.78 + 0.22 × min(days live with no token, 1460) / 1460. Time survived at size, without a token, is evidence a launch is a decision still to come (unknown listing date: 0.88).
  • Launch factor — 0.55 + 0.45 × the category's token share (smoothed): categories whose members usually launch score near 1; categories that usually stay tokenless are discounted.

Each protocol's detail view shows its own arithmetic, including the value if launched before the launch factor. Wrapped and exchange products are listed apart at the bottom — a claim on an asset that already trades is not a token that does not exist yet — and protocols already trading are shown at the market's own values, never the model's.
